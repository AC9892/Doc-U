# converters

Explains command converters.

Usage: `/converters` or `-converters`

Examples:
- `discord.Member`
- `discord.User`
- `discord.TextChannel`
- `discord.Role`
- `bool`
- `int`
- `float`
- custom `commands.Converter`

Converters are strongest in prefix commands. Slash commands use Discord-native option types.
