# polls

Guide for creating native Discord polls with discord.py.

Usage:
- `/polls`
- `-polls`

The guide explains:
- `discord.Poll`
- `poll.add_answer`
- `ctx.send(poll=poll)`
- `interaction.response.send_message(poll=poll)`
- `send_polls` permission
- poll vote events and raw poll vote events

This guide uses the shared guide buttons for examples and extra details.
