# cmdlist

Shows a detailed embedded command list with buttons.

Usage:
- `/cmdlist`
- `-cmdlist`
- `-commands`
- `-commandlist`

Features:
- Lists every loaded command from `AllCMDS`.
- Shows slash usage, prefix usage, description, and category.
- Splits commands across multiple embed pages when the list is long.
- Uses buttons for first page, previous page, next page, and last page.
- Includes a link button to the official discord.py documentation.
- Sends ephemerally when used as `/cmdlist`.

Only the user who requested the command list can control the page buttons.
